# Dart and Flutter Labs

Lab work from my mobile application development course: Dart language basics first, then a first Flutter app.

## What it covers

- Classes, objects and inheritance
- Abstract classes and mixins
- Lists and maps
- Anonymous and arrow functions
- Asynchronous functions (async / await)
- A first Flutter application (`Flutter_Application/`)

## How to run

Run a Dart file with `dart run <file>.dart`. For the Flutter app, open `Flutter_Application/` and run `flutter run`.
